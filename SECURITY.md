# Security Policy

This repository is a **partial source excerpt**, not a complete reproducible or audited release. It must not be relied on as evidence that a production deployment is safe.

For confidential vulnerability reports, potential exposed credentials, and sensitive deployment findings, email **hello@dfrchain.com**. Include only the minimum necessary reproduction and do not post live credentials or customer data in public issues.

If a credential is exposed, immediately revoke and rotate it. Removing source or rewriting Git history alone does not make a credential safe.

No guaranteed response timeline or formal bug bounty is offered.
